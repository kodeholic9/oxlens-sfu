> ★**공개본** — 문서군(§1 RULE-DOC-FAMILY 표) 가운데 ★**이 연동규격서 하나만 공개한다.** 표에 있는 다른 문서(서버 · SDK 정의서 · 시험 항목서 · 운영 규격서 · hook 규격서 · 정책서)는 공개하지 않는다. 이 문서는 그것들을 인용하지 않으므로 이것만으로 읽힌다.
